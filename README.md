# sohan.website

Personal portfolio. Next.js (App Router) + React-three-fiber/Drei + GSAP + Zustand + Tailwind, statically exported and deployed to GitHub Pages via GitHub Actions.

```bash
npm install
npm run dev    # http://localhost:3000
npm run build  # static export in ./out
```

Deploys automatically on push to `main`. Custom domain is set via `public/CNAME`.
